class brom_drake.systems.video.camera_spec.CameraSpec(name: str, X_PC: RigidTransform = <factory>, width: int = 640, height: int = 480, fov_y: float = 0.7853981633974483, fps: float = 30.0, parent_body_name: str | None = None, clipping: Tuple[float, float]=(0.01, 10.0))[source]¶

Description

A lightweight description of a camera that should record a video of a simulation.

The pose X_PC follows Drake’s camera convention: the camera looks along its +Z axis, +X points to the right of the image and +Y points down the image. If you would rather specify where the camera is and what it should look at, use CameraSpec.looking_at().

Parameters

name: str

A unique name for the camera. It is used to name the systems added to the diagram and the output video file (<name>.mp4).

X_PC: RigidTransform, optional

The pose of the camera in its parent frame (the world frame, unless parent_body_name is given). Default is the identity.

width: int, optional

Image width in pixels. Must be even (required by H.264). Default is 640.

height: int, optional

Image height in pixels. Must be even (required by H.264). Default is 480.

fov_y: float, optional

Vertical field of view in radians. Default is pi/4.

fps: float, optional

Frames per second of simulation time to capture. Default is 30.0.

parent_body_name: str, optional

If given, the camera is rigidly attached to this body of the production’s plant (e.g., a wrist camera). Default is None (camera fixed in the world).

clipping: Tuple[float, float], optional

The (near, far) clipping distances in meters. Default is (0.01, 10.0).

Usage

from brom_drake.all import CameraSpec

front = CameraSpec.looking_at(
    "front",
    position=[1.5, 0.0, 1.0],
    target=[0.0, 0.0, 0.3],
)

class brom_drake.systems.video.render_settings.RenderSettings(background_rgb: Tuple[float, float, float] | None = None, lights: Sequence[LightParameter] | None = None, cast_shadows: bool = False, exposure: float | None = None, shadow_map_size: int = 2048)[source]¶

Description

How the cameras’ renderer draws the scene: background color, lights, shadows and exposure. These settings apply to the whole renderer, which is shared by every camera of a production.

Any field left as None keeps Drake’s default (a light-blue background and a single light attached to each camera).

Parameters

background_rgb: Tuple[float, float, float], optional

The background color, with components in [0, 1].

lights: Sequence[LightParameter], optional

The lights in the scene. Use frame="world" for lights fixed in the scene, or frame="camera" for lights that move with each camera.

cast_shadows: bool, optional

Whether lights cast shadows. Default is False.

exposure: float, optional

Enables tone mapping with this exposure (useful with bright lights).

shadow_map_size: int, optional

The resolution of the shadow maps, when shadows are on. Higher values give sharper shadows with fewer dark artifacts, at some rendering cost. Default is 2048 (Drake’s own default, 256, leaves visible blotches on large surfaces).

Usage

production.add_cameras(cameras, render_settings=RenderSettings.studio())

class brom_drake.systems.video.video_recorder.VideoRecorder(output_path: str | Path, fps: float, name: str = 'video_recorder')[source]¶

Description

A Drake LeafSystem that captures color images from its input port at a fixed rate (in simulation time) and streams them into an MP4 file.

Frames are written to disk as they are captured (not held in memory), so long simulations do not exhaust RAM. Call save() once the simulation has finished to close the file.

Because the recorder only reads its input when a frame is due, an upstream RgbdSensor only renders at the recorder’s frame rate.

Parameters

output_path: Union[str, Path]

Where to write the MP4 file. Parent directories are created as needed.

fps: float

The number of frames to capture per second of simulation time. This is also the playback frame rate of the video.

name: str, optional

The name of this system. Default is “video_recorder”.

Ports

color_image: AbstractValue[ImageRgba8U]

The image to record (e.g., an RgbdSensor’s color_image output).

property first_frame_time: float | None¶

The simulation time of the first captured frame (None if no frames).

property is_saved: bool¶

property num_frames: int¶

Description

Adds one camera (an RgbdSensor) and one VideoRecorder to builder for every CameraSpec. Each recorder writes <output_dir>/<name>.mp4.

A VTK render engine is added to scene_graph (if it does not already have one named renderer_name). Only geometries with the perception role are visible to the cameras; MultibodyPlant gives this role to visual geometries from URDF/SDF files by default.

Parameters

builder: DiagramBuilder

The builder to add the systems to. It must contain scene_graph, unless query_object_port is given.

scene_graph: SceneGraph

The SceneGraph that holds the geometry to render.

camera_specs: Sequence[CameraSpec]

The cameras to add. Names must be unique.

plant: MultibodyPlant, optional

Required only if a spec uses parent_body_name.

output_dir: Union[str, Path], optional

The directory to write videos into. Default is ./brom/videos.

renderer_name: str, optional

The name of the render engine to use/create.

renderer_backend: str, optional

The VTK backend (”” for Drake’s default, “EGL” for headless Linux, “GLX”, or “Cocoa” on macOS). Default is “”.

query_object_port: OutputPort, optional

The port that the cameras read geometry from. Use this when scene_graph lives inside a nested diagram (e.g., a station) that exports its query object port; the port must belong to a system in builder. Default is None (use scene_graph.get_query_output_port()).

render_settings: RenderSettings, optional

Background, lights and shadows for the renderer. Only applies when this call creates the renderer (it raises if a renderer named renderer_name already exists). Default is None (Drake’s defaults).

Returns

recorders: List[VideoRecorder]

The recorders, in the same order as camera_specs.

brom_drake.systems.video.grid.combine_videos_into_grid(sources: Sequence[GridSource], output_path: str | Path, columns: int | None = None, tile_size: Tuple[int, int] | None = None, fps: float | None = None, label_tiles: bool = True, background_rgb: Tuple[int, int, int] = (16, 18, 22)) → Path[source]¶

Description

Combines several camera videos into one MP4 that shows all of them side by side in a grid. The videos are aligned by simulation time: each frame of the grid shows, for every camera, the latest frame captured at or before that time. Cameras may have different frame rates and resolutions.

Parameters

sources: Sequence[GridSource]

The videos to combine, in the order they should fill the grid (left to right, top to bottom).

output_path: Union[str, Path]

Where to write the combined MP4.

columns: int, optional

The number of columns in the grid. Default is ceil(sqrt(n)).

tile_size: Tuple[int, int], optional

The (width, height) of each tile. Each video is scaled to fit inside it, preserving its aspect ratio. Default is the first source’s resolution.

fps: float, optional

The frame rate of the combined video. Default is the highest source fps.

label_tiles: bool, optional

Whether to draw each camera’s name on its tile. Default is True.

background_rgb: Tuple[int, int, int], optional

The color of empty grid cells and letterboxing.

Returns

output_path: Path

The path of the combined video.

brom_drake.systems.video.video_recorder._close_unsaved_recorders()[source]¶

Closes every video that is still open when Python exits.

An MP4 that is never closed has no index and cannot be played. Relying on __del__ is not enough: during interpreter shutdown it can run too late (or not at all) to finish the file.
